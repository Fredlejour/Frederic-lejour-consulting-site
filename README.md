# Lejour Consulting

Site premium moderne pour `Lejourconsulting.com`, orienté consulting business senior, développement commercial, relation stratégique, growth et acquisition.

## Stack

- Vite
- React
- CSS responsive personnalisé
- Lucide React pour les icônes

## Installation

Node.js doit être installé sur la machine.

```bash
npm install
```

## Lancement local

```bash
npm run dev
```

## Build production

```bash
npm run build
```

## Prévisualisation du build

```bash
npm run preview
```
